# RepoMind Agent 工作流说明

RepoMind Agent 采用“Agent 分析—人工确认—Agent 生成—人工复核”的协作模式。

1. **仓库扫描**：统计项目文件、识别入口文件、依赖文件、测试目录和文档目录。
2. **结构分析**：根据文件名和目录组织推断项目模块职责。
3. **质量检查**：识别硬编码路径、宽泛异常处理、文档缺失、测试不足等问题。
4. **文档生成**：生成 README 草稿、运行命令、目录结构说明和输出产物说明。
5. **报告输出**：生成 Markdown 与 HTML 两种形式的质量报告。
6. **测试建议**：根据核心模块生成单元测试建议和覆盖率提升计划。
